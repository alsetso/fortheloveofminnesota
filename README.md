# For the Love of Minnesota

Web v2 — Next.js in `apps/web_v2`. This is the new primary web surface.

## Local

```bash
cp env.local.example env.local
# fill the SHARED block
./scripts/install-local-env.sh
./scripts/dev-web-v2.sh
```

Opens [http://localhost:3001](http://localhost:3001).
